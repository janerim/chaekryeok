# 개인정보 처리방침 — 책력

**시행일: 2026년 11월 4일**

책력(Chaekryeok)은 읽은 책을 달력에 기록하는 독서 앱입니다.
개발자는 **어떤 개인정보도 수집하지 않습니다.**

## 수집하는 정보

없습니다.

이 앱에는 서버가 없습니다. 회원가입도, 로그인도, 계정도 없습니다.
분석 도구나 광고 SDK를 넣지 않았습니다.

## 기기에 저장되는 것

아래 정보는 **사용자의 기기 안에만** 저장됩니다. 개발자는 이 정보에 접근할 수 없습니다.

| 저장 항목 | 내용 |
|---|---|
| 독서 기록 | 제목, 저자, 출판사, 장르, 읽기 시작한 날, 다 읽은 날, 평점, 한줄 감상, 메모와 독후감 |
| 읽고 싶은 책 | 제목, 저자, 출판사, 장르, 메모 |
| 독서 목표 | 연도별 목표 권수 |
| 표지 이미지 | 사용자가 고른 이미지 |

앱을 삭제하면 이 정보는 기기에서 함께 삭제됩니다.
앱 안의 **통계 → 백업 / 복원 → 전체 데이터 삭제** 로도 언제든 전부 지울 수 있습니다.

## 외부와 통신하는 경우

아래 두 경우에만 앱이 외부와 통신합니다. 독서 기록은 보내지 않습니다.

### 표지 이미지 검색

표지를 찾을 때 앱 안에서 네이버 이미지 검색을 엽니다. 이때 검색어가 네이버로 전달되고,
사용자가 이미지를 고르면 그 이미지가 올라가 있는 서버에서 내려받습니다.
이 과정에는 해당 서비스의 개인정보 처리방침이 적용됩니다.
이 기능을 쓰지 않으면 이 통신은 일어나지 않습니다.

### 새 버전 확인

새 버전이 나왔는지 알려 드리기 위해 Apple App Store 에서 앱의 최신 버전 정보를 조회합니다.
이 조회에 사용자의 기록은 포함되지 않습니다.

## 백업

**통계 → 백업 / 복원** 에서 내보내기를 누르면 기록이 파일 하나로 만들어집니다.

- 파일은 기기 안에 저장되어 파일 앱의 책력 폴더에서 볼 수 있습니다.
- 내용이 클립보드에 복사되고, 공유 시트가 열립니다.
- 공유 시트에서 사용자가 직접 고른 곳으로만 보내지며, 앱이 스스로 어딘가로 전송하지 않습니다.

백업 파일에는 독서 기록과 표지 이미지가 들어 있으니, 보관하는 곳은 신중하게 골라 주세요.

## 기기 권한

앱은 카메라, 마이크, 사진, 위치, 연락처 권한을 요청하지 않습니다.
