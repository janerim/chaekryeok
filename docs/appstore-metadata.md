# App Store 등록 문구

App Store Connect 에 그대로 붙여 넣는 텍스트다. 형식과 문장은 집중력 저장소의
`docs/appstore-metadata.md` 와 맞췄다. 스토어에서 직접 고치면 무엇을 왜 바꿨는지 남지
않으니, 고칠 때는 이 파일을 먼저 고친다.

각 항목의 글자 수 제한이 다르고 한글도 한 글자로 센다. 아래 숫자는 현재 길이다.
언어는 한국어 하나만 둔다.

---

## 앱 이름 (2 / 30자)

```
책력
```

---

## 부제 (9 / 30자)

> 집중력의 "나만의 집중 타이머" 와 짝을 이룬다. 앱 이름은 이미 함께 표시되므로 넣지 않는다.

```
나만의 독서 달력
```

---

## 프로모션 텍스트 (66 / 170자)

> 빌드를 새로 올리지 않고도 언제든 바꿀 수 있는 항목이다.
> 둘째 줄은 집중력과 함께 쓰는 문장이다. 바꾸려면 집중력 쪽도 같이 바꾼다.

```
다 읽은 날 칸에 표지가 놓입니다. 한 달을 넘겨 보면 무엇을 읽었는지 바로 보입니다.
하루하루가 쌓여 기록이 됩니다.
```

---

## 키워드 (56 / 100자)

> 쉼표 뒤에 공백을 넣지 않는다 — 공백도 글자 수에 들어간다.
> 앱 이름과 부제에 있는 낱말(책력, 나만의, 독서, 달력)은 이미 색인되므로 단독으로 넣지 않는다.

```
책,독후감,서평,도서,독서기록,독서노트,독서습관,책읽기,완독,캘린더,읽고싶은책,표지,통계,목표,기록장
```

---

## 설명 (636 / 4000자)

> 첫 세 줄만 접히지 않고 보인다. 거기서 이 앱이 무엇인지 끝나야 한다.
> 마지막 줄은 프로모션 텍스트 둘째 줄과 같은, 집중력과 함께 쓰는 문장이다.
> "어디로도 전송되지 않습니다" 라고 쓰지 않는 이유는, 표지를 찾을 때 앱 안에서 네이버
> 이미지 검색을 열기 때문이다. 저장되는 곳만 말한다.

```
책력은 읽은 책을 달력에 기록하는 독서 앱입니다.

다 읽은 날 칸에 표지가 놓입니다. 한 달을 넘겨 보면 무엇을 읽었는지 바로 보입니다.


■ 달력으로 한눈에

읽기 시작한 날부터 다 읽은 날까지 한 권의 여정이 달력에 이어집니다.
읽는 중, 완독, 중단한 책을 구분해서 보여 줍니다.


■ 표지는 검색해서 바로

앱 안에서 이미지 검색을 열고, 마음에 드는 표지를 누르면 저장됩니다.


■ 내 방식대로 기록

장르, 저자, 출판사, 평점, 한줄 감상을 남깁니다.
메모와 독후감은 읽는 중간중간 나눠 적을 수 있고, 작성 시각과 함께 시간순으로 쌓입니다.


■ 읽고 싶은 책

읽고 싶은 책을 모아 둡니다. 읽기 시작하면 기록으로 옮겨집니다.


■ 올해의 독서 목표

한 해 동안 읽을 권수를 정하면 달력과 통계에서 진행률을 볼 수 있습니다.
다 읽은 날을 기준으로 세고, 중단한 책은 넣지 않습니다.


■ 독서 통계

최근 12개월의 월별 완독 권수, 장르 분포, 평균 독서 기간, 평균 평점을 봅니다.


■ 기록은 이 기기 안에

독서 기록은 이 기기 안에만 저장되고, 앱을 지우면 함께 사라집니다.
표지까지 파일 하나로 백업해 두면 새 iPhone 에서 그대로 복원할 수 있습니다.


하루하루가 쌓여 기록이 됩니다.
```

## 이번 버전의 새로운 기능 (1.1.0)

> 업데이트는 이 항목이 필수다. 앱의 새 버전 안내 팝업이 이 문구를 그대로 보여 준다.
> 지난 버전의 문구는 [RELEASE_NOTES.md](../RELEASE_NOTES.md) 에 있다. 고치면 거기도 같이 고친다.

```
• 올해 읽을 권수를 정하는 독서 목표가 생겼어요. 통계 탭에서 정하고 고칠 수 있어요.
• 달력 탭과 통계 탭에서 목표까지 얼마나 왔는지 볼 수 있어요.
• 다 읽은 날을 기준으로 세고, 중단한 책은 넣지 않아요.
• 백업에 목표도 함께 담겨요. 예전 백업도 그대로 복원할 수 있어요.
• 아이콘과 시작 화면이 새로워졌어요.
```

## 심사 메모

> 심사 중에 막힐 만한 것을 미리 적어 둔다. 계정이 없고, 표지 찾기에 웹뷰를 쓴다.

```
로그인이나 계정 없이 바로 사용할 수 있습니다.

앱은 서버가 없으며 독서 기록은 기기 안에만 저장합니다.

표지 찾기는 앱 안의 웹뷰로 네이버 이미지 검색을 열고, 사용자가 고른 이미지를 기기에
저장하는 기능입니다. 새 버전 안내를 위해 App Store 에서 최신 버전 정보를 조회합니다.
```
